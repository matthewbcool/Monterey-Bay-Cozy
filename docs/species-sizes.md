# Creature size references

Reviewed October 14, 2026; great white shark added October 15, giant sea bass October 17 and gray whale October 24, 2026. The Tank now shows a **range**, with a **Size notes** disclosure containing its basis, sources and the current model's actual authoring size. `src/models/sizeRanges.ts` is the machine-readable source of truth; each `FishEntry` requires a `sizeRange`.

These are reference guides, not minimum/maximum bounds for every individual, fishing limits, or probability distributions. Published ranges are retained where available. A reference span combines stated endpoints with different meanings; a selected range contains an explicitly documented authoring choice. Exact inch conversions are stored in metres; the UI rounds centimetres for readability. Source measurement definitions are preserved below rather than silently mixing standard, fork, total, shell and bell lengths.

## Implementation boundaries

- A range is informational. It does not resize existing models, drive a random size distribution, or change swim speed. Models may be smaller than an adult reference span.
- Factories continue to receive one physical `lengthMeters` (or jelly bell size), with root scale one. Geometry, anchors and collider dimensions scale together. The range must never become a viewer scale multiplier.
- Turtle `shellLengthMeters` is derived from its carapace profile; full-body `lengthMeters` remains the factory/physics input. These measurements are not interchangeable.
- The sardine school's existing ±10% specimen variation is retained; it is an artistic distribution around 25 cm, not a sample drawn from this reference interval.
- New creatures need a required catalogue range, measurement, evidence basis, note and source links. If a source supplies only one size, document any selected endpoint; do not invent a published interval.
- `tests/species-sizes.test.ts` checks coverage, dimensions, conversions, provenance and unchanged model scales. The focused turtle/jelly browser test checks every label/source disclosure and a 320 px layout on WebGPU and WebGL 2.

## Giant Pacific octopus

The selector reports **Arm span range · 2–4 m** from [Monterey Bay Aquarium](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/giant-pacific-octopus). The source permits larger animals, so 4 m is not a maximum. The chosen procedural specimen represents a 3 m fully extended span; its curled or jetting envelope is smaller. `armSpanMeters` scales geometry, arm frames, coarse collider and attachment anchors together, leaving the public root unscaled. It is not a 3 m mantle or a measured individual.

# Reporting a security concern

Please do not post credentials, personal information or exploitable security details in public issues. Contact the project maintainer privately through the Monterey Bay Tech Discord server to arrange a private report. Include the affected version, reproduction steps and potential impact, with sensitive values removed. There is no guaranteed response time or paid bounty program.

This release is a browser prototype. Multiplayer accounts and a hosted contribution backend are not implemented. If you deploy a fork or add server-side features, you own its configuration, dependencies, credentials and user-data handling.
